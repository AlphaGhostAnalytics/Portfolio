How each one gets built

Python
Clean the raw data, handle missing values, run EDA to see what the data can actually answer.
Figma
Wireframe the dashboard layout before opening Power BI, so visuals aren't rearranged after the fact.
Power BI
Build the real dashboard with DAX measures, calculated columns, and interactive filters.
README
Document the business questions, cleaning decisions, and any issues solved along the way.
